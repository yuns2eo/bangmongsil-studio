# 소품 이미지 로컬 사본

힉스필드 Element와 **같은 이미지**를 내려받아 둔 것이다. 힉스필드 크레딧이 없거나 MCP가 안 붙을 때 ChatGPT 경로(`CLAUDE.md` 작업 순서 6번 경로 B)에서 첨부용으로 쓴다.

- 파일명 = Element 이름. `CLAUDE.md` Element 표의 이름을 그대로 찾으면 된다
- 전부 1254 × 1254 PNG, 2026-11-09 기준 Element 원본
- 힉스필드 경로에서는 이 파일을 쓰지 않는다. `<<<ID>>>`가 서버에서 같은 이미지를 주입한다

| 폴더 | 내용 | 장수 |
|---|---|---|
| `studio/` | 쿠폰 6종 & 펫프 선물상자 5종 & 펫프 코인 6종 | 17 |
| `detail/` | 몽실 손바닥 & 발바닥 패드 | 2 |
| `petf/common/` | 펫프 아이콘 공통 | 18 |
| `petf/cat/` | 펫프 아이콘 고양이 | 14 |
| `petf/dog/` | 펫프 아이콘 강아지 | 8 |

## 알아둘 것

**1. 배경색이 두 종류다.** `studio/` 쿠폰 6종과 `detail/` 패드 2종은 흰 배경, 나머지는 검정 배경이다. 힉스필드 Element로 쓸 때는 문제가 없었지만, ChatGPT에 직접 첨부하면 검정 배경이 결과에 묻어날 수 있다. 첨부 경로로 쓸 때는 프롬프트에 배경을 명시하고, 결과에 검정 테두리나 어두운 반사가 생기는지 본다. 아직 검증 안 됨.

**2. `펫프_선물상자_뚜껑`은 한 장뿐이다.** `CLAUDE.md`는 2장 묶음(덮인 모습 & 공중에서 아랫면 보임)이라고 적어 뒀지만, Element에 등록된 미디어는 덮인 모습 한 장이다. **아랫면 이미지는 이 폴더에 없다.** 뚜껑 아랫면이 필요한 장면은 원본을 따로 찾아 넣어야 한다.

## 다시 받는 법

Element 미디어 URL에서 받는다. `manage_reference_elements`(action `list`)로 각 Element의 `medias[0].url`을 얻어 그대로 내려받으면 된다. 파일명만 Element 이름으로 바꾼다.
